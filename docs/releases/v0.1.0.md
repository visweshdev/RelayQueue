# RelayQueue v0.1.0

First public release of RelayQueue, a Python 3.12 job queue backed by PostgreSQL and Redis. The
project is available under the MIT License.

- Submit and schedule jobs through FastAPI, then follow their results and attempt history in the
  browser dashboard. Workers recover abandoned jobs through expiring leases and fenced completion.
- Run the sales CSV demo to produce a durable revenue report. The recovery walkthrough kills the
  worker processing a file checksum, validates the retried result and checks the lease-expiry metric.
- Compare one, two, and four workers under a CSV workload with queue latency, end-to-end latency,
  and sampled container resources.

Start with the [clean-install walkthrough](https://github.com/visweshdev/RelayQueue/blob/v0.1.0/docs/getting-started.md)
and [deployment boundaries](https://github.com/visweshdev/RelayQueue/blob/v0.1.0/docs/production-readiness.md).
Compose is the full-system install path. The attached wheel and source distribution contain the
Python package, and their SHA-256 digests are in `SHA256SUMS`.

The examples run on a local, single-host stack. Jobs execute at least once, so downstream effects
need separate idempotency. Local measurements describe the tested machine and workloads.

If you are new to RelayQueue, please try the walkthrough and
[share your results in an issue](https://github.com/visweshdev/RelayQueue/issues/new).
Include the release tag, operating system, Docker and Compose versions, and the first step where your
results differed. Redact credentials and job payloads from logs.
